# failed-to-get-creator-info

## What the user sees

When this error appears, it means the creator information could not be retrieved.

Example API response:

```json
{
  "type": "https://github.com/Diogoarnauth/Hubly-Ps/docs/errors/failed-to-get-creator-info",
  "message": "Failed To Get Creator Info",
  "status": 404
}
```

## What to do

- Try again later.
- If the issue continues, contact support.

## Why this happens

- The backend failed while fetching creator details.
- The requested creator could not be found or loaded.

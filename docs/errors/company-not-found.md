# company-not-found

## What the user sees

When this error appears, it means the requested company could not be found.

Example API response:

```json
{
  "type": "https://github.com/Diogoarnauth/Hubly-Ps/docs/errors/company-not-found",
  "message": "Company Not Found",
  "status": 404
}
```

## What to do

- Verify the company information and try again.
- Use a different company or search criteria.

## Why this happens

- The company does not exist in the system.
- The request referenced an invalid company ID.

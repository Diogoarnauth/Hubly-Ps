# invalid-sector-name

## What the user sees

When this error appears, it means the selected sector name is invalid.

Example API response:

```json
{
  "type": "https://github.com/Diogoarnauth/Hubly-Ps/docs/errors/invalid-sector-name",
  "message": "Invalid Sector Name",
  "status": 404
}
```

## What to do

- Select a valid sector name from the available list.
- Check the sector input and try again.

## Why this happens

- The sector name does not match any supported option.
- The value may be missing or incorrect.

# failed-to-get-creator-social-profile-info

## What the user sees

When this error appears, it means the system could not retrieve creator social profile information.

Example API response:

```json
{
  "type": "https://github.com/Diogoarnauth/Hubly-Ps/docs/errors/failed-to-get-creator-social-profile-info",
  "message": "Failed To Get Platforms",
  "status": 404
}
```

## What to do

- Try again later.
- If the issue persists, contact support.

## Why this happens

- There was an issue retrieving the social profile platforms.
- The creator’s platform data could not be loaded.

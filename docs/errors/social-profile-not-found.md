# social-profile-not-found

## What the user sees

When this error appears, it means the requested social profile could not be found.

Example API response:

```json
{
  "type": "https://github.com/Diogoarnauth/Hubly-Ps/docs/errors/social-profile-not-found",
  "message": "Social Profile Not Found",
  "status": 404
}
```

## What to do

- Verify the social profile ID or platform.
- Try again or choose a different profile.

## Why this happens

- The social profile does not exist in the system.
- The profile may have been deleted or never created.

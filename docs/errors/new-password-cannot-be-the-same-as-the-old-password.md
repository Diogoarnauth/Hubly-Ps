# new-password-cannot-be-the-same-as-the-old-password

## What the user sees

When this error appears, it means the new password matches the current password.

Example API response:

```json
{
  "type": "https://github.com/Diogoarnauth/Hubly-Ps/docs/errors/new-password-cannot-be-the-same-as-the-old-password",
  "message": "New Password Cannot Be The Same As The Old Password",
  "status": 400
}
```

## What to do

- Choose a different password than the current one.
- Use a stronger password with new characters.

## Why this happens

- The new password entered is identical to the existing password.
- The system requires a changed password for security.

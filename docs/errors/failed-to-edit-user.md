# failed-to-edit-user

## What the user sees

When this error appears, it means the system could not update your account details.

Example API response:

```json
{
  "type": "https://github.com/Diogoarnauth/Hubly-Ps/docs/errors/failed-to-edit-user",
  "message": "Failed To Edit User",
  "status": 400
}
```

## What to do

- Try submitting the update again.
- If the problem continues, contact support.

## Why this happens

- The request could not be processed by the backend.
- There may be a validation or server issue preventing the update.

# user-already-registered-as-company

## What the user sees

When this error appears, it means the user is already registered as a company.

Example API response:

```json
{
  "type": "https://github.com/Diogoarnauth/Hubly-Ps/docs/errors/user-already-registered-as-company",
  "message": "User Already Registered As Company",
  "status": 409
}
```

## What to do

- Use the existing company account instead of creating a new one.
- If this is a mistake, contact support for help.

## Why this happens

- The user account is already linked to a company profile.
- The system does not allow the same user to register as a company again.

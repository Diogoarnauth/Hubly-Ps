# tag-name-already-exists

## What the user sees

When this error appears, it means the tag name is already in use.

Example API response:

```json
{
  "type": "https://github.com/Diogoarnauth/Hubly-Ps/docs/errors/tag-name-already-exists",
  "message": "Tag Name Already Exists",
  "status": 409
}
```

## What to do

- Choose a different tag name.
- Avoid using a duplicate tag name.

## Why this happens

- The tag name already belongs to another tag.
- Duplicate tag names are not allowed.

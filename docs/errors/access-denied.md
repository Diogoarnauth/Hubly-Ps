# access-denied

## What the user sees

When this error appears, it means the action is not allowed for the current user.

Example API response:

```json
{
  "type": "https://github.com/Diogoarnauth/Hubly-Ps/docs/errors/access-denied",
  "message": "Access Denied",
  "status": 403
}
```

## What to do

- Make sure you are signed in with the correct account.
- If you think this is an error, contact support.

## Why this happens

- The user does not have permission for the requested action.
- The resource is restricted to other roles or accounts.

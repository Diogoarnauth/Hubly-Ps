# user-already-registered-as-creator

## What the user sees

When this error appears, it means the user is already registered as a creator.

Example API response:

```json
{
  "type": "https://github.com/Diogoarnauth/Hubly-Ps/docs/errors/user-already-registered-as-creator",
  "message": "User Already Registered As Creator",
  "status": 409
}
```

## What to do

- Use the existing creator profile instead of creating a new one.
- If this is wrong, contact support for assistance.

## Why this happens

- The user already has a creator account.
- The system blocks duplicate creator registrations.

# user-not-found

## What the user sees

When this error appears, it means the requested user account could not be found.

Example API response:

```json
{
  "type": "https://github.com/Diogoarnauth/Hubly-Ps/docs/errors/user-not-found",
  "message": "User Not Found",
  "status": 404
}
```

## What to do

- Verify that the correct user was selected.
- Try again with a different account or search criteria.

## Why this happens

- The user account does not exist.
- The user ID or lookup criteria were invalid.

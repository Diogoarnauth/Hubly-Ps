# message-not-found

## What the user sees

When this error appears, it means the requested message could not be found.

Example API response:

```json
{
  "type": "https://github.com/Diogoarnauth/Hubly-Ps/docs/errors/message-not-found",
  "message": "Message Not Found",
  "status": 404
}
```

## What to do

- Verify the message exists.
- Try refreshing the conversation.

## Why this happens

- The requested message was deleted or never existed.
- The message ID may be invalid.

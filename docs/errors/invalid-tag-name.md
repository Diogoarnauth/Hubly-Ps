# invalid-tag-name

## What the user sees

When this error appears, it means the tag name is invalid.

Example API response:

```json
{
  "type": "https://github.com/Diogoarnauth/Hubly-Ps/docs/errors/invalid-tag-name",
  "message": "Invalid Tag Name",
  "status": 400
}
```

## What to do

- Choose a valid tag name.
- Remove invalid characters or use a different name.

## Why this happens

- The tag name does not meet validation rules.
- It may be blank, too long, or contain unsupported characters.

# old-password-is-incorrect

## What the user sees

When this error appears, it means the current password entered is incorrect.

Example API response:

```json
{
  "type": "https://github.com/Diogoarnauth/Hubly-Ps/docs/errors/old-password-is-incorrect",
  "message": "Old Password Is Incorrect",
  "status": 400
}
```

## What to do

- Check the current password and enter it again.
- If you forgot the password, use the password recovery option.

## Why this happens

- The current password does not match the account record.
- The user typed the wrong password when verifying their identity.

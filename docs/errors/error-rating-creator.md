# error-rating-creator

## What the user sees

When this error appears, it means there was an error while rating the creator.

Example API response:

```json
{
  "type": "https://github.com/Diogoarnauth/Hubly-Ps/docs/errors/error-rating-creator",
  "message": "Error Rating Creator",
  "status": 400
}
```

## What to do

- Try the rating action again.
- If the error keeps happening, contact support.

## Why this happens

- The rating request could not be completed.
- There may be a server or validation problem.

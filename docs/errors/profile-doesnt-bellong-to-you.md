# profile-doesnt-bellong-to-you

## What the user sees

When this error appears, it means the selected profile does not belong to the current user.

Example API response:

```json
{
  "type": "https://github.com/Diogoarnauth/Hubly-Ps/docs/errors/profile-doesnt-bellong-to-you",
  "message": "Profile Doesnt Bellong To You",
  "status": 403
}
```

## What to do

- Use a profile that belongs to your account.
- Do not try to access someone else’s profile.

## Why this happens

- The requested profile is owned by another user.
- Access to that profile is forbidden.

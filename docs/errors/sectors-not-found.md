# sectors-not-found

## What the user sees

When this error appears, it means the requested sectors could not be found.

Example API response:

```json
{
  "type": "https://github.com/Diogoarnauth/Hubly-Ps/docs/errors/sectors-not-found",
  "message": "Sectors Not Found",
  "status": 404
}
```

## What to do

- Try again later.
- If the problem persists, contact support.

## Why this happens

- The sector data could not be found.
- The request referenced invalid or unavailable sectors.

# failed-to-update-status

## What the user sees

When this error appears, it means the system could not update the status.

Example API response:

```json
{
  "type": "https://github.com/Diogoarnauth/Hubly-Ps/docs/errors/failed-to-update-status",
  "message": "Failed To Update Status",
  "status": 400
}
```

## What to do

- Try the update again.
- If the problem persists, contact support.

## Why this happens

- The update request could not be processed.
- There may be a validation or server issue preventing the change.

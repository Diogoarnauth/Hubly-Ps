# social-profile-already-exists

## What the user sees

When this error appears, it means a social profile already exists for that platform.

Example API response:

```json
{
  "type": "https://github.com/Diogoarnauth/Hubly-Ps/docs/errors/social-profile-already-exists",
  "message": "Social Profile Already Exists",
  "status": 409
}
```

## What to do

- Use the existing social profile instead of creating a duplicate.
- If this is wrong, contact support.

## Why this happens

- The selected platform already has a profile linked.
- Duplicate social profiles are not allowed.

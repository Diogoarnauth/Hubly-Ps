# code-already-exists

## What the user sees

When this error appears, it means the code you are trying to create already exists.

Example API response:

```json
{
  "type": "https://github.com/Diogoarnauth/Hubly-Ps/docs/errors/code-already-exists",
  "message": "Code already exists",
  "status": 400
}
```

## What to do

- Use a different code or identifier.
- Check whether the code already belongs to another account or item.

## Why this happens

- The code is already registered in the system.
- Duplicate values are not allowed for this field.

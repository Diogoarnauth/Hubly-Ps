# invalid-country-headquarters

## What the user sees

When this error appears, it means the country selected for headquarters is invalid.

Example API response:

```json
{
  "type": "https://github.com/Diogoarnauth/Hubly-Ps/docs/errors/invalid-country-headquarters",
  "message": "Invalid Country Headquarters",
  "status": 400
}
```

## What to do

- Choose a valid country for your company headquarters.
- Correct the country selection and try again.

## Why this happens

- The selected country is not accepted by the backend.
- The field may be empty or contain invalid data.

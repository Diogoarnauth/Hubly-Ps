# tag-not-found

## What the user sees

When this error appears, it means the requested tag could not be found.

Example API response:

```json
{
  "type": "https://github.com/Diogoarnauth/Hubly-Ps/docs/errors/tag-not-found",
  "message": "Tag Not Found",
  "status": 404
}
```

## What to do

- Check the tag selection and try again.
- Use a different tag if necessary.

## Why this happens

- The requested tag does not exist.
- The tag may have been deleted.

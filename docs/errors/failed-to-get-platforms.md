# failed-to-get-platforms

## What the user sees

When this error appears, it means platform data could not be loaded.

Example API response:

```json
{
  "type": "https://github.com/Diogoarnauth/Hubly-Ps/docs/errors/failed-to-get-platforms",
  "message": "Failed To Get Platforms",
  "status": 404
}
```

## What to do

- Try again later.
- If the issue persists, contact support.

## Why this happens

- The platform list could not be retrieved from the backend.
- The requested platform data was unavailable.

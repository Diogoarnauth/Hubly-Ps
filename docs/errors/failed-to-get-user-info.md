# failed-to-get-user-info

## What the user sees

When this error appears, it means the system could not retrieve the user information.

Example API response:

```json
{
  "type": "https://github.com/Diogoarnauth/Hubly-Ps/docs/errors/failed-to-get-user-info",
  "message": "Failed to get user information",
  "status": 404
}
```

## What to do

- Refresh the page or retry the operation.
- If the problem continues, contact support.

## Why this happens

- The requested user information could not be found.
- The user account may not exist or may be unavailable.

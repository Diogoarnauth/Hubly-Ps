# internal-server-error

## What the user sees

When this error appears, it means the server encountered an unexpected problem.

Example API response:

```json
{
  "type": "https://github.com/Diogoarnauth/Hubly-Ps/docs/errors/internal-server-error",
  "message": "InternalServerError",
  "status": 500
}
```

## What to do

- Try again after a short time.
- If the error persists, contact support.

## Why this happens

- The backend failed while processing the request.
- There may be a problem with the server or application logic.

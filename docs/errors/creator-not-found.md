# creator-not-found

## What the user sees

When this error appears, it means the requested creator profile could not be found.

Example API response:

```json
{
  "type": "https://github.com/Diogoarnauth/Hubly-Ps/docs/errors/creator-not-found",
  "message": "Creator Not Found",
  "status": 404
}
```

## What to do

- Check that the creator profile exists.
- Use a different search or selection, or try again.

## Why this happens

- The creator profile does not exist.
- The request referenced an invalid creator ID.

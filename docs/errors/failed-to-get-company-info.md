# failed-to-get-company-info

## What the user sees

When this error appears, it means the system could not retrieve company information.

Example API response:

```json
{
  "type": "https://github.com/Diogoarnauth/Hubly-Ps/docs/errors/failed-to-get-company-info",
  "message": "Failed To Get Company Info",
  "status": 500
}
```

## What to do

- Try again later.
- If the issue persists, contact support.

## Why this happens

- The backend failed while fetching company data.
- There may be a server error or temporary failure.

# unauthorized-access

## What the user sees

When this error appears, it means the user is not authorized to access the resource.

Example API response:

```json
{
  "type": "https://github.com/Diogoarnauth/Hubly-Ps/docs/errors/unauthorized-access",
  "message": "Unauthorized Access",
  "status": 403
}
```

## What to do

- Make sure you are signed in with the correct account.
- If you believe this is a mistake, contact support.

## Why this happens

- The user lacks permission for this action.
- The resource is restricted to other roles or accounts.

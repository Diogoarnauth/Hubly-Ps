# platform-not-found

## What the user sees

When this error appears, it means the requested platform could not be found.

Example API response:

```json
{
  "type": "https://github.com/Diogoarnauth/Hubly-Ps/docs/errors/platform-not-found",
  "message": "Platform Not Found",
  "status": 404
}
```

## What to do

- Verify the platform selection and try again.
- Use a different platform if necessary.

## Why this happens

- The platform is not registered in the system.
- The request referenced an invalid platform ID.

# failed-to-create-user

## What the user sees

When this error appears, it means the system could not create your account at this time.

Example API response:

```json
{
  "type": "https://github.com/Diogoarnauth/Hubly-Ps/docs/errors/failed-to-create-user",
  "message": "Failed to create User",
  "status": 500
}
```

## What to do

- Try again after a short moment.
- If the problem continues, contact support or try again later.

## Why this happens

- A server error occurred while saving your account.
- The request was valid, but the backend could not complete the operation.

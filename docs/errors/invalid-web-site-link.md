# invalid-web-site-link

## What the user sees

When this error appears, it means the website link entered is not valid.

Example API response:

```json
{
  "type": "https://github.com/Diogoarnauth/Hubly-Ps/docs/errors/invalid-web-site-link",
  "message": "Invalid Web Site Link",
  "status": 404
}
```

## What to do

- Check the website URL for typos.
- Enter a valid website address, including the domain.

## Why this happens

- The URL format does not match the expected rules.
- The website link may be missing or malformed.
